# Ball Battle — New System

리뉴얼 v230을 기반으로 공통 전투 규칙부터 다시 구축하는 프로젝트.

## 현재 상태
- 기존 캐릭터 등록 초기화. 실제 캐릭터는 아직 없음.
- 전투 준비 화면, 전투장, 시작/일시정지/리셋, 배속, 전투장 색 및 전체 화면 제공.
- 개인전/팀전, 랜덤 선택, 전원 참가/해제, 인원별 맵 크기, 피해량 확인.
- 전체 조합 각 50전 / 선택 1명 대 전원 각 50전 / 선택한 2명 100전.
- 진행률, 테스트 중단, 상성표, 전적 복사/리셋 및 브라우저 저장.
- 음량/효과음 설정 및 패치노트. 캐릭터가 없는 동안 전투/테스트 버튼은 비활성화.
- QWER 네 슬롯의 공통 시전/쿨타임 관리.
- 물리/마법 피해, 방어력/마법저항력, 5속성 피해 보정.
- 공통 CC 및 강제 이동 종료 후 이동 복귀.
- 속성은 element-1~5 임시 식별자. 명칭과 배율은 추후 결정.
- legacy/renewal-v230.html은 원본 보관본이며 새 게임에서 실행하지 않음.

index.html을 정적 웹 서버로 열면 실행됩니다. 캐릭터는 src/characters.js에 등록합니다.
규칙 및 다음 작업은 docs/SYSTEM.md와 docs/PATCH_CONTEXT.md를 참고하세요.

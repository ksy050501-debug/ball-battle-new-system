# 공통 전투 규칙 / Common combat rules

## 확정된 요구
- 기존 캐릭터 초기화. 모든 신규 캐릭터는 Q/W/E/R 네 스킬을 가진다.
- 모든 피해는 physical 또는 magic. 방어력 또는 마법저항력으로 감소한다.
- 모든 피해에 5속성 중 하나를 지정한다. 캐릭터에도 하나의 고유 속성을 지정한다.
- CC와 이동/시전 상태는 공통 모듈을 이용한다.

## 초기 구현 및 조정 가능한 가정
- 속성 ID: element-1~5. 이름은 미정.
- 각 속성은 순환 순서상 다음 두 속성에 강하고 이전 두 속성에 약하다.
- 같은 속성 1배, 강점 1.15배, 약점 0.85배. 초기 임시값이다.
- 피해 = 기본 피해 × 100/(100+저항력) × 속성 배율.
- 체력 및 피해 계산은 소수 정밀도를 보존한다. 화면 체력만 올림 표시한다.
- 음수 저항력/관통은 아직 제공하지 않는다.
- 쿨타임은 시전 시작 시 소비. 시전 취소 시 환불하지 않는다.
- 하나의 시전이 끝나기 전 다음 스킬을 시작하지 않는다.
- 자동 사용은 Q→W→E→R 순서로 사용 가능한 첫 기술. 캐릭터별 우선순위는 추후 확장.
- 사거리/조건 불충족이면 쿨타임을 소비하지 않는다.
- 스킬의 execute에서 피해는 applyDamage, CC는 applyCC, 강제 이동은 forceMove를 호출한다.

## CC
- slow: 가장 강한 둔화만 적용. 각각 만료시각을 보존하여 강한 둔화 종료 후 약한 둔화가 남을 수 있다.
- root: 일반 이동 및 movement 스킬 차단.
- stun: 이동과 모든 스킬 차단, 현재 시전 취소.
- silence: 이동 허용, 모든 스킬 차단, 현재 시전 취소.
- 같은 root/stun/silence: 기존 만료시각과 새 만료시각 중 더 늦은 것을 선택.
- forceMove: 넉백/끌어당김용 속도와 만료시각 지정. 현재 시전 취소.
- 강제 이동은 속박/기절 중에도 적용. displacement 면역은 이를 차단.
- 면역은 damage/slow/root/stun/silence/displacement를 개별 지정.
- 기본 이동속도는 CC나 강제 이동으로 덮어쓰지 않는다.
- 만료 후 CC 목록에서 제거하고 기본 이동으로 복귀.
- 사망 시 CC·시전·강제 이동 제거. 변신 구현시 clearTransient를 호출할 것.

## 현재 한계
실제 캐릭터, 돌진 전용 상태, 투사체 및 공격 이펙트는 아직 신규 모듈에 이식하지 않았다. 팀전, 전적 및 전투 시뮬레이터는 v0.2에서 복원했다.
리뉴얼 v230 원본은 legacy/renewal-v230.html에 보존했다.
시스템을 전부 이식했다는 의미가 아닌 첫 기반 커밋이다.


## 전투 및 자동 테스트 (v0.2)
- 일반 전투와 자동 테스트는 src/world.js의 createWorld/stepWorld를 공유한다.
- 고정 갱신 간격 1/60초, 제한 시간 500초. 둘 이상 살아 있으면 시간초과 무승부.
- 모든 조합 각 50전, 선택 1명 대 나머지 각 50전, 선택 2명 100전 제공.
- 자동 테스트는 개인전이며 simOnly/neutral/summon을 대상에서 제외한다.
- 전적 평균잔HP는 승리한 경기의 잔HP 평균. 무승부는 별도 집계.
- 중단시 완료된 조합만 보관. 자동 테스트는 기존 화면 전투를 덮어쓰지 않는다.
- 팀전 선택은 미선택→A→B→해제. 랜덤 팀전은 최대 3vs3.
- 효과음 버튼은 UI 효과음 설정. 신규 공격 사운드는 추후 스킬과 함께 추가한다.
